# PRD — tts-server-proxy

- **Status:** ✅ In production (built and end-to-end tested)
- **Platform:** Android 15/16 (minSdk 26), built from WSL with Gradle 8.10.2 + JDK 17 + SDK 35
- **Package:** `it.ttsserverproxy`
- **Last updated:** 2026-11-02 (v0.4.0: English UI/docs, GitHub release)

## Problem

Android apps use the system `TextToSpeech` API, but without a TTS engine configured they
have no voices (or are stuck with cloud-bound ones). This project provides system voices
generated by an OpenAI-compatible Qwen3-TTS server on the LAN.

## Goal

Expose a Qwen3-TTS server on the LAN as a native Android TTS engine, with a configuration
UI (endpoint, models, voices) that requires nothing hard-coded.

## Architecture

```
┌──────────────┐  TextToSpeech   ┌────────────────────┐  HTTP POST        ┌──────────────────┐
│  Any Android │ ──── bind ────► │  tts-server-proxy  │ ────────────────► │ Qwen3-TTS server │
│  app         │ ◄── PCM 16bit ─ │  (TTS engine)      │ ◄── WAV / MP3 ─── │ (OpenAI-style)   │
└──────────────┘                 └────────────────────┘ /v1/audio/speech  └──────────────────┘
```

- `LanTtsService extends TextToSpeechService` — the actual engine; runs HTTP inside
  `onSynthesizeText()` (on a dedicated synthesis thread) and streams PCM to the system via
  `SynthesisCallback`. Promotes itself to a **foreground service** while synthesizing.
- `AudioDecoder` — decodes MP3 (or other compressed audio) into 16-bit PCM with `MediaCodec`.
- `MainActivity` — configuration: endpoint, API key, model list (one Android voice each).
- `TestActivity` — synthesis test through the public `TextToSpeech` API.
- `DiagActivity` — engine diagnostics, config import (via `adb push`), in-app service log.

## Functional requirements

### R1 — A new system TTS engine
A real `TextToSpeechService`: an engine selectable in *Settings → System → Languages &
input → Text-to-speech output*.

### R2 — Engine registration
In `AndroidManifest.xml` the service must declare:

```xml
<service
    android:name=".LanTtsService"
    android:permission="android.permission.BIND_TEXT_TO_SPEECH_ENGINE"
    android:exported="true"
    android:foregroundServiceType="mediaPlayback">
    <intent-filter>
        <action android:name="android.intent.action.TTS_SERVICE" />
        <category android:name="android.intent.category.DEFAULT" />
    </intent-filter>
    <meta-data android:name="android.speech.tts" android:resource="@xml/tts_engine" />
</service>
```

**Important:** the permission must be `BIND_TEXT_TO_SPEECH_ENGINE` (not
`BIND_TEXT_SERVICE`, which is for spell checkers) — otherwise the engine never shows up.

### R3 — Server API
`POST {endpoint}/v1/audio/speech` (configurable endpoint):

```json
{
  "model":  "qwen3-tts-1.7b_G0",
  "voice":  "clone:VoceItalianaAdulta",
  "input":  "Text to speak",
  "response_format": "wav"
}
```

Response: WAV/MP3 audio. The client detects the container and decodes to PCM 16-bit.

### R4 — Configuration UI
Everything is editable and persisted in `SharedPreferences`:

- **Server endpoint** and **API key** (shared by all models).
- **Model list** (JSON): `label`, `model`, `voice`, `lang` — one Android voice each.
- Built-in **factory preset** (fallback when prefs are empty) so the engine speaks even
  on a fresh install or after a reboot without opening the app.

### R5 — Audio format
`SynthesisCallback` requires linear 16-bit PCM: WAV is parsed natively (zero transcoding),
anything else goes through `MediaCodec`.

## Non-functional requirements

- **minSdk 26, targetSdk 35** (Android 15/16).
- Dependencies: AndroidX AppCompat + Material Components only.
- **Resilience**: foreground service during synthesis (no process freezing with the screen
  off), 420 s read timeout (cold wake + boot + model load), network retries on fast
  failures, cancelled requests exit silently (no error dialogs).

## Development setup

- **Android SDK:** `~/android-sdk` (platform 35).
- **Gradle:** `~/opt/gradle-8.10.2`.
- **Build:** `export ANDROID_HOME=$HOME/android-sdk && gradle :app:assembleRelease`
- **Device testing:** enable wireless debugging, pair, then
  `adb install -r app/build/outputs/apk/release/app-release.apk`.
